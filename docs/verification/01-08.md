## Deviation from the charter

The charter says to restore into a separate temporary library, close the active database, keep a recovery copy, and switch libraries. The code validates the backup, writes a recovery copy, and then restores into the open database with SQLite's backup API, inside one transaction. The database file is not swapped. See the decision record for the trade-off and the options.
