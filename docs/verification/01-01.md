## Known limitations

- **`get-task-allow` is `true` in the ad-hoc Release build.** Notarization rejects this entitlement. Developer ID signing in 05-04 must turn it off.
- **Debug builds have no hardened runtime.** Xcode disables it for ad-hoc signing ("Disabling hardened runtime with ad-hoc codesigning"). The Release build has it on.
- **Test-signed builds carry Xcode-injected entitlements.** The Debug product signed for UI testing includes a read-only temporary exception for `/`, plus test-manager mach lookups. These are not in `Config/FDB.entitlements` and are not in the Release build. Do not ship a testing-configuration build.
- **Xcode device and simulator support is not functional here.** CoreDevice and CoreSimulator plug-ins do not match this macOS install. macOS builds and tests are not affected.
- **The project file was written by hand**, not by Xcode's new-project template. It builds with Xcode 27.0. Opening it in the Xcode GUI has not been checked, and a GUI save may rewrite parts of it.
- **The window was verified by an XCUITest,** not by a screenshot or a person looking at it.
