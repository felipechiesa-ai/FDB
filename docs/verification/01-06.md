- The profile image on screen. A screenshot of a profile with an image was not checked.

## Decisions and limits

- Images are re-encoded from their decoded pixels, with the orientation applied and no metadata. JPEG output uses quality 0.92. Originals are not downscaled, so the 6000-pixel limit applies.
- A file that is chosen and then cancelled stays in `media/originals/` without a reference. This is the orphan case the charter allows. Cleanup is not implemented yet.
- Limits: 25 MB and 6000 pixels per side. Only JPEG and PNG are accepted.
